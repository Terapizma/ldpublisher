## 📖 Our Story & Vision
For years, the Left 4 Dead 2 community had to struggle with command lines or outdated, obscure tools just to upload mods to the workshop or deal with VPK files. **LDPUBLISHER** was designed specifically to put an end to this struggle. Our goal was to provide mod developers and players with the smooth, modern, and sleek experience they deserve. After nights of coding, UI designing, and Steam integration testing, we built this framework where you can handle complex Workshop management with a single click. For us, this is not just a tool; it is a professional legacy left to the community.

## 🚀 Key Features

* 📦 **One-Click Workshop Publishing:** Select your raw mod folder, enter the details, and let LDPUBLISHER handle the rest. Automatic `addoninfo.txt` creation, VPK packaging, and Steam uploading are handled instantly in the background.
* 📥 **Advanced Download Manager:** It identifies and downloads not only individual mods but also massive Workshop Collections into folders using their ID. (Powered by SteamCMD in the background).
* 🛠️ **Built-in VPK Unpacker:** Instantly extract locked `.vpk` files you have or downloaded into editable raw files (models, materials, sound, etc.).
* 🎮 **SteamWorks Integration:** The app syncs with your Steam profile upon launch, updates your status to *"Left 4 Dead 2 in LDPUBLISHER,"* and provides direct access to your workshop items (likes, subscriber count, file size).
* 🎨 **Modern & Official UI:** Eye-friendly Dark Mode and fully professional, user-friendly dialogue screens.

## 💻 Technologies Used
This project is built on modern and stable infrastructures:
* **[Electron.js](https://electronjs.org/):** Powerful desktop application framework.
* **[Node.js](https://nodejs.org/):** Background operations, asynchronous file and process management.
* **[SteamWorks.js](https://github.com/ceifa/steamworks.js):** Steam API and Workshop integration.
* **Valve Core Tools:** VPK Tool (`vpk.exe`) and SteamCMD integrations.
